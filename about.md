# HBV Menu

A mod menu for Geometry Dash 2.2081 on Android, iOS, macOS and Windows.

Open it with the **HBV** button on the main menu or the pause screen.

- **Noclip** (with accuracy tracking)
- **Speedhack**
- **Icon Hack** (unlock all icons and colors)
- **Startpos Switcher** (on-screen arrows)
- **Show Hitboxes**
- **Info Label** (FPS, accuracy, cheat indicator)
- **Safe Mode** (cheated completions are not saved)
